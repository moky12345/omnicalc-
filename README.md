## ⚡ Overview & Value Proposition

Most calculators are limited to simple arithmetic. **OmniCalc** solves two distinct challenges in a unified, tactile interface:
1. **Precision Arithmetic Engine**: Instantaneous calculation with expression memory tape and physical keyboard event routing.
2. **E-Commerce ROAS & Profit Lab**: An interactive unit economics simulator for media buyers, store owners, and CRO designers to evaluate break-even ad spend, margins, and target ROAS before launching marketing campaigns.

---

## 📐 Dual Computational Modes

### 1. Standard Calculator
- **Stateful Arithmetic**: Clean handling of binary operations (`+`, `−`, `×`, `÷`), percentages (`%`), negation (`±`), and decimals.
- **Persistent Calculation Tape**: Sidebar history recording up to 20 past calculations with **1-click result recall** into the active register.
- **Tactile Ergonomics**: Full physical keyboard binding (`0-9`, `+`, `-`, `*`, `/`, `Enter` / `=`, `Backspace`, `Escape` for All Clear).

### 2. E-Commerce ROAS & Profit Lab
- **Unit Economics Inputs**:
  - Retail Selling Price ($ AUD)
  - Cost of Goods Sold / COGS ($ AUD)
  - Pick, Pack & Shipping Logistics ($ AUD)
  - Merchant & Gateway Processing Fees (%)
  - Customer Acquisition Cost / Target CPA ($ AUD)
- **Live Analytical Outputs**:
  - **Net Profit & Net Margin (%)**
  - **Break-Even ROAS Threshold**: Formula: `Selling Price / (Selling Price - Direct Costs)`
  - **Maximum Tolerable CAC**: Identifies the exact acquisition cap before operating at a loss
  - **Visual Revenue Allocation Bar**: 4-segment stacked distribution illustrating direct costs, logistics, advertising spend, and retained profit.

## 🚀 How to Run

1. Clone or download this repository:
   ```bash
   git clone https://github.com/moky12345/omnicalc.git
   cd omnicalc
   ```
2. Open `index.html` in your web browser.
3. Switch between **Standard Calculator** and **E-Commerce ROAS Lab** using the header pill switcher.
